## 1. 문서 개요
### 1-1. 목적
이 문서는 외부 서비스별로 **무엇을, 어떤 파라미터로 호출하고, 응답의 어떤 필드를 어디에 쓰는지**를 계약 수준으로 고정한다. 여기 없는 외부 호출은 구현하지 않는다 (SC-DT-010 · SC-DT-011).

## 가입 인증메일 (EI-MA)
- EI-MA-001 — 신규 가입의 이메일 소유 확인용 고정 템플릿만 발송한다. 서버가 Google Apps Script 웹 앱의 `/exec` URL로 HTTPS POST하고 스크립트 소유자의 Gmail 주소로 보낸다. 설정 절차는 `docs/이메일_인증_운영설정.md`를 따른다.
- EI-MA-002 — 서버 환경변수 `AUTH_MAIL_SCRIPT_URL` · `AUTH_MAIL_SECRET`을 사용한다. 같은 비밀값을 스크립트 속성에 저장한다. 요청은 version · verificationId · timestamp · email · code · HMAC-SHA256 signature이며 비밀값 원문은 전송하지 않는다. 120초 시각 검증·스크립트 잠금·요청 ID 처리 이력으로 위조 및 중복 발송을 막는다. 비밀값·코드·응답 원문은 로그에 남기지 않는다.
- EI-MA-003 — 30초 이내에 `{ok:true,verificationId}`를 확인해야 발송 완료로 처리한다. Google ContentService의 응답 조회용 리다이렉트만 GET으로 따른다. 오류·권한 미승인·설정 누락·쿼터 초과는 가입 API에서 503으로 처리하고 인증을 우회하지 않는다. 공급자 오류 원문은 사용자에게 전달하지 않는다.
- EI-MA-004 — 서비스 한도는 분당 10회·UTC 일일 100회, 이메일별 시간당 5회·재전송 60초다. 발송 실패도 요청 한도에 포함한다. Google 개인 계정의 수신자 한도(공식 문서 기준 일일 100회, 첫 요청 후 24시간 재설정)는 별도이며 변경될 수 있다. 스크립트는 실제 잔여 한도를 확인한다. 재전송도 한도를 사용하며 기존 로그인은 메일 장애의 영향을 받지 않는다.
- 2026.09.18 운영 확인: 실제 발송 성공·사용자 수신 확인, API·웹 배포 커밋 `1298b2a`, `/health`의 signupEmail·schema 정상. signupEmail은 설정 형식 확인이며 실제 도달 여부를 보증하지 않는다. 사용자가 직접 진행하는 운영 최종 가입 완료는 아직 확인하지 않았다.
