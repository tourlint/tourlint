# TourLint 심사위원 체험 가이드 — 2박 3일 한 상품으로 전 기능 따라 하기

**처음부터 끝까지 한 방향으로 따라 하면 TourLint 의 기능을 전부 거칩니다.** 로그인 → 상품 기획(장소 담기 포함) → 검수 · 수정안 · 리포트 · 출시 → 레이더 → 검수 기준 조정 순서입니다. 뒤에 따로 모아 둔 「추가 체험」 은 없습니다. 상품 하나(강릉 2박 3일)로 끝까지 갑니다. 소요 시간은 40 ~ 50분이고 외부 조회 시간에 따라 달라집니다.

[서비스 열기](https://tourlint-web.up.railway.app/) · 테스트 계정 `openapi@tourlint.kr` · 비밀번호는 제출 서류의 테스트 계정 항목을 사용하세요.

> 상품명의 ‘내이름’ 만 본인 이니셜로 바꾸고 나머지 값은 그대로 입력하세요. 아래 일정은 **문제를 일부러 넣은 연습 일정**입니다.
>
> 공용 계정입니다. 다른 상품은 건드리지 않습니다. 19단계에서 바꾸는 회사 기준은 **같은 단계 안에서 원래 값으로 되돌립니다.**
>
> 화면의 점수 · 건수 · 장소는 2026-09-19 실측값입니다. 관광정보와 이동시간은 실시간 조회라 값이 조금 다를 수 있습니다. 숫자가 같은지가 아니라 **근거 → 선택 → 일정 변경 → 새 결과**가 이어지는지를 보세요.

## 전체 흐름

| 단계 | 하는 일 | 거치는 기능 |
|---|---|---|
| 1 ~ 2 | 로그인 · 홈 | 단계별 현황, 보드/목록, 검색 · 정렬 |
| 3 ~ 6 | 새 상품 만들기 | 기본정보와 ‘자주 넣는 곳’, 지정 양식 내려받기 · 업로드, 자연어 붙여넣기, 직접 입력 · 장소 확인 · 기준, 등록 화면 장소 담기 |
| 7 ~ 9 | 기획 화면 | AI로 한 번에 찾기, 후보 검색, 직접 정한 곳, 운영정보 카드 · 이동시간, 장소 담기(숙소 · 분류 · 필터 · 정렬 · 걷기 길), 일정 편집 |
| 10 ~ 15 | 검수와 보완 | 첫 검수, 판단 근거 3단, 수정안 충돌 · 미리보기 · 확정 · 전후 비교, 검수 화면 장소 담기, 상품 구성 수정안(야간 일정 · 공예체험), 점수 하락 경고와 되돌리기, 전화로 물어볼 내용, 무시 |
| 16 | 산출물 | 검수 리포트 PDF, 출시 승인, 검수 목록 |
| 17 ~ 18 | 레이더 | 관심 키워드 · 관심 지역, 새 소식 확인, 근거, 수요 신호, 오늘 할 일, 날씨 판정 읽기 |
| 19 | 검수 기준 | 표준 · 규칙 설명, 회사 기준 조정 → 재검수 → 복원 |

## 1. 로그인

[서비스 열기](https://tourlint-web.up.railway.app/)에서 **로그인** 탭에 테스트 계정을 넣습니다. 옆의 **회원가입** 탭은 이메일 인증코드로 새 계정을 만드는 길입니다. 테스트 계정은 이미 가입돼 있어 누르지 않아도 됩니다.

![로그인 화면](assets/2026-09-19/00-login.png)

## 2. 홈에서 흐름 보기

상단 메뉴는 **홈 · 기획 · 검수 · 레이더** 순서이고 이 가이드도 같은 순서로 갑니다. 아래로 내려 **기획 중 · 검수 중 · 출시할 수 있음 · 출시함** 네 칸과 미리 준비된 상품들을 봅니다. **보드 / 목록** 전환, 검색란, **출발일순 · 준비도순 · 최근 검수순** 정렬을 한 번씩 눌러 봅니다. 다 봤으면 오른쪽 위 **새 상품 기획**을 누릅니다.

![홈 — 상품의 단계별 현황](assets/2026-09-19/01-home.png)

## 3. 기본정보 입력

| 화면 항목 | 입력값 |
|---|---|
| 상품명 | `[실습-내이름] 강릉 감성 2박 3일` |
| 시도 / 시군구 | 강원특별자치도 / 강릉시 |
| 출발일 | 2026-11-17 (화요일) |
| 박수 | 2박 3일 |
| 타깃 고객 / 상품 콘셉트 | 20대 / 감성 |
| 예상 인원 / 이동수단 | 15 / 자가용 |

지역과 출발일을 넣으면 오른쪽 **장소 담기**에 강릉의 장소 종류가 뜹니다.

![기본정보와 오른쪽 장소 담기](assets/2026-09-19/02-basic-info.png)

타깃과 콘셉트를 둘 다 고르면 그 아래에 **‘20대 · 감성 여행에 자주 넣는 곳’** 이 나옵니다 — 공예체험 · 카페/찻집 · 랜드마크관광 · 저녁 일정. 이 기준은 14단계의 ‘상품 구성’ 검수에 그대로 쓰입니다.

![타깃 · 콘셉트에 따른 자주 넣는 곳](assets/2026-09-19/03-profile-chips.png)

## 4. 지정 양식 내려받아 그대로 올려 보기

일정을 넣는 방법은 세 가지입니다 — 직접 입력, 엑셀·CSV 업로드, 자연어 붙여넣기. 셋을 이어서 써 봅니다.

1. **엑셀·CSV 업로드** 탭 → **지정 양식 내려받기**. 받은 파일(`tourlint_schedule_template.xlsx`)에는 예시 일정이 들어 있습니다.
2. **파일 선택**으로 방금 받은 파일을 그대로 올립니다.
3. **‘18개 항목을 불러왔습니다.’** 를 확인합니다. 박수도 파일의 최대 일차에 맞춰집니다.

![양식을 내려받아 그대로 업로드한 결과](assets/2026-09-19/04-upload.png)

## 5. 자연어로 실습 일정 넣기

**자연어 붙여넣기** 탭으로 옮겨 아래 상자를 통째로 붙여넣고 **일정으로 바꾸기**를 누릅니다. 나중에 넣은 것이 앞의 것을 대체하므로 4단계의 예시 18개는 이 일정으로 바뀝니다.

```text
강릉 감성 2박 3일
1일차 10:00~11:30 강릉 경포대 관광
1일차 11:00~12:30 강릉 오죽헌·시립박물관 관광
1일차 13:00~14:00 가람집옹심이 식사
1일차 15:00~16:00 강릉 경포벚꽃축제 관광
2일차 09:00~10:00 경포해변 관광
2일차 10:00~11:00 안목해변 관광
2일차 11:00~12:00 정동진해변 관광
2일차 16:00~17:00 주문진해변 관광
3일차 09:00~09:30 강릉역 집결
3일차 12:30~13:30 초당할머니순두부 식사
```

**‘10개 항목으로 바꿨습니다.’** 가 나오면 **직접 입력에서 편집**을 누릅니다. 1일차 4개 · 2일차 4개 · 3일차 2개가 표로 들어와 있습니다. ‘강릉역 집결’ 은 유형 **이동**으로 읽힙니다.

![자연어를 일정표로 바꾼 결과](assets/2026-09-19/05-natural-language.png)

## 6. 직접 입력으로 보완하고 저장 전에 장소 담기

### 6-1. 숙소 한 줄을 직접 입력

**2일차** 탭 → **+ 항목 추가** → 시작 **18:00**, 장소명에 **세인트존스** 를 입력합니다. **‘강릉시에서 찾은 곳 1곳’** 아래의 **세인트존스 호텔**을 누르고 유형을 **숙박**으로 바꿉니다. 종료는 비워 둡니다.

![장소명을 치면 관광정보에서 후보를 찾는다](assets/2026-09-19/06-direct-input-search.png)

### 6-2. ‘기준’ 을 체크해 근처 3km 보기

방금 넣은 숙소 줄 왼쪽의 **기준**을 체크합니다. 오른쪽 장소 담기가 **“세인트존스 호텔” 근처**로 바뀌고 **식당 · 카페 · 숙소**가 눌립니다. **카페**를 눌러 거리순 목록과 **다음 →** 페이지를 봅니다. 여기서는 보기만 합니다.

![기준 줄 근처 3km 의 카페](assets/2026-09-19/07-anchor-nearby.png)

### 6-3. 저장 전에 장소 하나 담기

장소 담기에서 **랜드마크관광**을 누르고 **주문진 등대**의 **일정에 넣기** → 일차 **3일차**, 넣을 위치 **초당할머니순두부 다음 (맨 뒤)** → **여기에 넣기**. 왼쪽 **3일차** 탭에 새 줄이 생기면 시작에 **14:30** 을 넣고 종료는 비웁니다(종료를 비우면 분류별 기본 체류시간이 적용됩니다). **저장하고 장소 고르기**를 누릅니다.

![등록 화면에서 일차와 위치를 골라 담기](assets/2026-09-19/08-register-picker-form.png)

## 7. 기획 화면 — 이름을 실제 관광정보에 연결하기

저장하면 같은 상품의 기획 화면으로 넘어갑니다. 이름이 하나로 정해지는 곳은 이미 **고른 곳**이고, **경포해변**과 **강릉역** 두 곳이 **고르는 중**으로 남습니다.

1. **AI로 한 번에 찾기**를 누릅니다. AI 는 후보와 이유를 내놓을 뿐이고 확정은 사람이 누릅니다. 후보가 나오면 **이곳으로 선택**, 아래처럼 못 찾았다고 하면 다음으로 갑니다.

   ![AI 가 찾은 결과와 못 찾은 이유](assets/2026-09-19/12-ai-suggest.png)

2. 경포해변 줄의 **장소 찾기** → 검색란에 공식 이름 **경포해수욕장** → **고르기**.

   ![공식 이름으로 검색해 후보 고르기](assets/2026-09-19/13-manual-search.png)

3. 강릉역 줄은 **찾는 곳이 없나요? 직접 정한 곳으로 두기**를 누릅니다. 집결지처럼 관광정보에 없는 곳은 **직접 정한 곳**으로 두며, 운영정보 검수 대상에서 빠집니다.

   ![직접 정한 곳 — 검수에서 빠지는 일정](assets/2026-09-19/14-custom-place.png)

**‘모든 장소를 골랐어요’** 가 뜨면 카드들을 읽어 봅니다. 가람집옹심이의 **쉬는 날 · 매주 화요일**, 경포벚꽃축제의 **행사 기간 2026-04-04 ~ 04-11**, 오죽헌의 **이용 · 영업시간**, 접혀 있는 **요금 · 주차 정보**, 카드 사이의 **앞 장소에서 차로 약 N분**. 1일차가 화요일이고 축제는 4월이라는 점이 10단계에서 차단으로 잡힙니다.

## 8. 장소 담기 — 숙소 · 분류 · 필터 · 정렬 · 걷기 길

### 8-1. 1일차 숙소

오른쪽 장소 담기에서 **넣을 일차 1일차** → **넣을 위치 강릉 경포벚꽃축제 다음** → **숙소**. **하이오션 경포**의 **자세히**로 주소 · 이용시간 · 주차 · 무장애 편의를 읽고 **일정에 넣기**. 왼쪽 1일차 끝에 **16:04 · 숙박**으로 들어옵니다 — 앞 일정 종료 16:00 에 조회된 이동 4분을 더한 값입니다. 목록에 없으면 다른 호텔을 담으세요.

![근처 3km 숙소의 상세정보](assets/2026-09-19/15-picker-lodging-detail.png)

### 8-2. 분류 · 필터 · 정렬

**넣을 일차 2일차** → **넣을 위치 정동진해변 다음** → 분류 칩 **전시시설**(25곳). **휠체어 가능**을 체크하면 21곳, **반려동물 동반**은 1곳으로 줄어듭니다. 체크를 풀고 **함께 많이 가는 순**을 누르면 **하슬라아트월드 · 함께 많이 가는 곳 4위**가 맨 위에 옵니다. 이 카드의 **일정에 넣기**를 누르면 2일차에 **12:05 – 13:35** 로 들어옵니다(정동진해변 종료 12:00 + 이동 5분, 전시시설 기본 체류 90분).

![무장애 · 반려동물 · 실내 필터](assets/2026-09-19/16-picker-filter-wheelchair.png)

![함께 많이 가는 순 정렬](assets/2026-09-19/17-picker-sort-together.png)

### 8-3. 걷기 길

**넣을 일차 3일차**로 바꾸고 아래 **걷기 길**에서 **해파랑길 35코스 바우길 09구간**(10km · 약 210분)의 **일정에 넣기**. 걷기 길은 **직접 정한 곳**으로 들어가며 3일차 맨 끝에 붙습니다.

![걷기 길 — 거리 · 시간 · 난이도](assets/2026-09-19/18-walk-trails.png)

## 9. 일정 편집으로 시간과 순서 다듬기

상단 **일정 편집**을 누릅니다. 장소 담기가 채운 시각은 초안입니다.

- **1일차** — 하이오션 경포 시작을 **18:00** 으로.
- **3일차** — 걷기 길을 **09:30 – 12:00** 으로 바꾸고 **↑** 를 두 번 눌러 강릉역 다음으로 올립니다.

**저장**을 누르면 기획 화면으로 돌아옵니다. 여기까지 1일차 5개 · 2일차 6개 · 3일차 4개, 모두 15개 일정입니다.

![일정 편집 — 시각과 순서](assets/2026-09-19/19-edit-day3.png)

## 10. 첫 검수

**검수 시작 →** → 설명창의 **검수 시작**. 결과 화면에 ‘아직 검수하지 않았습니다’ 가 보이면 **검수 실행**을 누르고 기다립니다.

![검수를 시작하기 전 안내](assets/2026-09-19/21-start-audit-sheet.png)

**실측: 출시 준비도 0점 · 차단 2 · 오류 4 · 주의 4 · 확인 불가 1.** 점수 아래에 감점 계산식과 조회 시각 · 데이터 지문 · 규칙셋이 나옵니다. 왼쪽 **현재 일정표**는 문제 카드나 수정안을 고를 때 관련 장소를 강조합니다.

![첫 검수 — 0점, 출시 불가](assets/2026-09-19/22-first-audit-summary.png)

| 필터 | 이 일정에서 나오는 문제 | 이유 |
|---|---|---|
| 차단 | 가람집옹심이 쉬는 날 | 1일차가 화요일, 매주 화요일 휴무 |
| 차단 | 경포벚꽃축제 행사 기간 | 4월에 끝난 행사를 11월에 방문 |

| 오류 | 경포해변 → 안목해변, 안목해변 → 정동진해변 | 이동에 13분 · 35분이 걸리는데 배정 0분 |
| 주의 | 종류 쏠림 2건 | 관광지 7곳, 바다 · 강 풍경 4곳 |

## 19. 검수 기준 — 확인하고, 조정하고, 되돌리기

오른쪽 위 **검수 기준**을 누릅니다. 맨 위 **표준**은 모든 계정에 같고 바꿀 수 없습니다 — 등급별 감점, 같은 유형 3곳 이상, 연속 일정 6시간, 최소 식사 60분. 아래 **규칙 설명**에서 R01 ~ R10 의 **설명**을 펼쳐 무엇을 보고 어떤 데이터를 쓰는지 읽습니다. 더 아래에는 기본 체류시간 · 실내/야외 · 타깃별 기대 구성 표가 있습니다.

**회사 기준**은 표준보다 엄격하게만 정할 수 있습니다.

1. **최소 식사 시간**에 **45** 를 넣어 봅니다. **‘표준 60분보다 짧게는 정할 수 없어요’** 가 뜨고 저장이 막힙니다.
2. **90** 으로 바꾸고 **저장**. 아래 **변경 이력**에 **최소 식사 시간 60 → 90** 이 남습니다.

   ![회사 기준 저장과 변경 이력](assets/2026-09-19/67-standard-saved.png)

3. **검수 → 내 상품 → 검수 결과 보기 → 지금 재검수**. 회사 기준은 다음 검수부터 적용되고 과거 결과는 그대로입니다. **실측: 77점**, 요약에 **‘회사 기준: 식사 90분’** 이 붙습니다.

   ![회사 기준으로 다시 검수한 요약](assets/2026-09-19/68-company-standard-audit.png)

4. **주의** 필터에 식사 · 휴식 카드가 둘 생깁니다 — **‘식사가 60분으로 회사 기준 90분보다 짧습니다. TourLint 표준 60분은 충족합니다.’** 표준과 회사 기준을 구분해서 말합니다.

   ![표준은 충족하지만 회사 기준에 못 미치는 식사](assets/2026-09-19/69-r07-company-standard.png)

5. **반드시 되돌립니다.** **검수 기준 → 최소 식사 시간 60 → 저장**. 변경 이력에 **90 → 60** 이 추가됩니다. 공용 계정이라 다른 심사위원의 검수에도 영향을 주는 값입니다. 내 상품을 한 번 더 **지금 재검수**하면 85점으로 돌아옵니다.

   ![회사 기준을 원래 값으로 복원](assets/2026-09-19/70-standard-restored.png)

마지막으로 오른쪽 위 계정 메뉴에서 **로그아웃**합니다. 다시 로그인하면 상품과 검수 결과, 출시 상태가 그대로 남아 있습니다.
