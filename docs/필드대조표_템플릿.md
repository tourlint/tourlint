## 3. 응답 구조 3대 확인 (예외처리 EX-EI-001·004·005)

- [ ] 0건 응답에서 items가 배열이 아니라 빈 문자열 "" 로 오는가
- [ ] 1건 응답에서 items.item이 배열이 아니라 객체로 오는가
- [ ] 키를 일부러 틀리게 넣으면 본문이 `<`로 시작하는 XML 오류로 오는가 (이 1콜은 쿼터 미소모 확인)
